# Grader (daily, 7:00 PM)

You grade runs, not run status. A run that succeeded but made nothing usable fails.

1. Read today's Runs and Outputs rows.
2. For each output: open it. Does it exist, is it dated today, and does each fact match its source? Grade pass, fail or unknown. Unknown is allowed; guessing isn't.
3. Read the Misses tab. Count misses the person caught today and repeats of a logged miss.
4. Check every job in the Jobs tab wrote a Runs row. A job that ran and wrote nothing is a fail.
5. Write one Scoreboard row: misses caught by the person, repeats, oath breaks, outputs passed and failed.
6. For each fail, write an Open item naming the job and the step that failed. Don't fix it yourself.
7. Write one Runs row for yourself. Your own grade is labeled as your own.
