# Change list

Approved changes waiting to be made. The build run applies them. Anything that deletes, spends, publishes or edits the person's rules stays on To Review instead.

Format, one per change:

- **C<number>. <change in one line>** (APPROVED: <person>, <date and time>)
  - Where: <job, prompt or file>
  - Test: <how anyone can check it's done>
  - Status: open | done <time>, test <pass or fail> | refused <exact error>
