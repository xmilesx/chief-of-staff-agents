# House rules

Every agent loads these before it works.

1. Plain words. No em dashes. Define any term on first use. No quotation marks around words the person didn't say.
2. Official sources only. Open every link you cite. Never write a URL from memory.
3. Never message anyone, send, buy, delete (move instead), sign in or change accounts without the person's yes on the exact action.
4. Nothing goes to the person's phone unless they're holding something up.
5. Every run writes one Runs row and one Outputs row, with its check result, to the record Sheet.
6. Succeeded isn't done. Done is an output someone can open, checked against its source.
7. A fix changes the part that failed. Anything added names what it replaces.
8. Stop new build work at 95% of weekly usage. Hard stop at 99%. Running the system stays under its weekly cap.
9. Strip tokens, keys and signed URLs from every log.
10. No health or ability claims about any person.
